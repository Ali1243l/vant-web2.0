# مراجعة VANT — 27 أكتوبر 2026

## نطاق الفحص

فهرسة ملفات المشروع كاملة (219 ملفاً وقت الفهرسة، دون المكتبات ونتائج البناء)، فحص TypeScript والبناء، مراجعة نقاط الدخول والإعدادات والإيميلات وتخزين البيانات وصلاحيات SQL، وتجربة البحث وتفاصيل المنتج في المتصفح. هذا لا يعني اختبار كل سيناريو في كل شاشة. لا توجد إعدادات Supabase محلية؛ اختبارات قاعدة البيانات الحية والإرسال الفعلي لم تنفذ.

لم يوجد AGENTS.md أو CLAUDE.md داخل المشروع. تعليمات المستخدم الخاصة بـ graphify محترمة؛ ملف Claude العام يطلب تشغيله عند `/graphify` فقط. جرى الاطلاع على مكتبة مهارات Claude واختيار المهارات المرتبطة بالمهمة.

## ما تم إصلاحه

- إزالة مفتاح Resend المضمّن من السيرفر والمتصفح وإلغاء إرسال الإيميلات مباشرة من المتصفح أو تحويل بيانات العملاء إلى خدمة احتياطية.
- الإرسال يعتمد على متغير السيرفر RESEND_API_KEY فقط. غياب المفتاح يعيد 503 وفشل المزود يعيد 502؛ نجاح HTTP وحده لا يكفي لإظهار نجاح الإرسال.
- عدم تسجيل رسالة فاشلة ضمن الحملات المرسلة. اختبارات محلية لا ترسل رسائل حقيقية.
- توحيد مسار الإيميل المحلي مع مسار الإنتاج وإضافة حد لحجم الطلب المحلي والتحقق من شكل البيانات.
- تحميل لوحة الإدارة عند فتحها فقط: ملف واجهة البداية انخفض من 2,340.98 إلى 766.81 كيلوبايت قبل الضغط، وبالضغط من 627.52 إلى 231.23 كيلوبايت. الأرقام تخص بناء المراجعة وقد تختلف قليلاً مع تحديث المكتبات.
- منع ظهور «تحميل المزيد» حين تكون المنتجات المحلية مكتملة أو تكون استجابة الوكيل قد أعادت كل المنتجات.
- إصلاح خلل تأكد في المتصفح: سعر قطعة 35 ألف كان يتحول إلى 45 ألف داخل السلة. تمرير السعر والمقاس واللون الحقيقي، فصل خيارات القطعة، مزامنة العدادات، ومنع الإضافة دون مقاس أو لقطعة غير متاحة. إصلاح رابط واتساب الذي كان يقرأ تسمية الإعداد بدلاً من رقم الهاتف. السلال القديمة لا تملك بيانات الخيارات الكافية لإعادة بناء أسعارها آلياً؛ أعد إضافة القطع القديمة بعد التحقق منها.
- تحديث قالب البيئة ودليل التشغيل إلى React + Vite، وربط المعاينة بعنوان محلي فقط.
- أمر تنظيف يعمل على Windows وأمر فحص يجمع الأنواع والاختبارات والبناء.
- اعتماد npm وإزالة ملف Bun الموازي، وتحديث package-lock.json ليتطابق مع package.json، وتحديث esbuild إلى نطاق يدعمه Vite وتحديث body-parser داخل نطاق Express المتوافق. آخر فحص npm بعد التحديث أعاد صفر ثغرات معروفة.
- إضافة GitHub Actions لفحص الأنواع والاختبارات والبناء والثغرات لكل push وpull request؛ نجاحه على GitHub يحتاج تحققاً مستقلاً بعد الرفع.
