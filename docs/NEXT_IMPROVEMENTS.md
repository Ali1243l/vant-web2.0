# معاينة الموبايل وخطة التحسين

## معاينة الموقع كجوال

على الكمبيوتر افتح http://127.0.0.1:3000/ في Chrome أو Edge، ثم F12 لفتح أدوات المطور وCtrl+Shift+M لتفعيل محاكاة الأجهزة. اختر عرض 390 وارتفاع 844، أو جهازاً جاهزاً، وجرّب اللمس والسكرول. يُفضّل التحقق أيضاً بعرض 320 و768.

هذه محاكاة لشاشة الجوال على الكمبيوتر. عنوان 127.0.0.1 لا يفتح نفس سيرفر الكمبيوتر من تلفون آخر؛ الاختبار على هاتف فعلي يحتاج عنواناً متاحاً عبر الشبكة المحلية أو استضافة معاينة. السيرفر الحالي محصور بالكمبيوتر عمداً.

## ما تم تنفيذه في الشريط

اللوكو المتحرك والبحث والسلة والمفضلة واللغة والثيم تبقى داخل الترويسة العائمة. التصنيفات تظهر عند بداية الصفحة أو الصعود قليلاً، وتختفي عند النزول، مع عتبة حركة تمنع تبدّلها بسبب تحركات صغيرة. أزرار الترويسة بمساحة لمس 44 بكسل، والتصنيفات المخفية لا تستقبل التركيز بالكيبورد.

## الباكيند: قبل إطلاق متجر عام

هذه النتائج مبنية على ملفات المشروع؛ صلاحيات قاعدة بيانات حية لم يتم تدقيقها مباشرة.

1. **مصادقة وصلاحيات إدارة على السيرفر:** استبدال أقفال المتصفح والرموز الافتراضية بجلسات موثوقة ودور إدارة محدد. إخفاء الواجهة وحده لا يحمي البيانات.
2. **تصحيح RLS:** ملفات SQL الحالية تسمح للـ anon بالكتابة والحذف. الزائر يقرأ الكتالوج فقط؛ تعديل المنتجات والصور والإعدادات يحتاج صلاحية مدير موثقة.
3. **خصوصية المشتركين:** نقل بيانات البريد من ملفات التخزين العام إلى جدول أو مساحة خاصة، مع سياسات قراءة وحذف ومدة احتفاظ واضحة.
4. **حماية خدمة الإيميل:** إلغاء المفتاح القديم المكشوف، وقوالب سيرفر، وتحقق من المستلم، وصلاحيات لإرسال الحملات وحدود إرسال مناسبة. لا يقبل مسار عام إرسال HTML لأي عنوان بلا ضوابط.
5. **طلبات وأسعار ومخزون موثوقة:** حفظ الطلب على السيرفر قبل أو مع تحويله إلى واتساب، وحساب السعر والخصم من بيانات السيرفر، وحفظ اختيار المقاس واللون وسعره وقت الطلب، ومنع الطلبات المكررة وتعارض المخزون.
6. **حفظ ومزامنة يمكن الوثوق بهما:** إظهار تأكيد قاعدة البيانات أو فشلها، ومعالجة التعديلات المتزامنة وعدم اعتبار التخزين المحلي بديلاً عن نجاح الحفظ السحابي.
7. **تشغيل الإنتاج:** توحيد مسارات API بين المحلي والاستضافة، ومراقبة الأخطاء، وسجل تغييرات للإدارة، ونسخ احتياطية مع اختبار الاسترجاع.

الترتيب المقترح: حماية الإدارة والبيانات أولاً، ثم تثبيت رحلة الطلب، ثم تحسين السرعة والتفاصيل البصرية. تقرير الأدلة التفصيلي في PROJECT_REVIEW.md.
